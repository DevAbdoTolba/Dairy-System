# ADR-0001: قرارات الاستضافة والتخزين الأساسية

الحالة: مقبول

يستخدم المشروع Next.js كتطبيق واحد على Vercel وMongoDB Atlas كتخزين دائم. استبدل هذا القرار SQLite المحلي لأن المالك يستخدم جهازاً لوحياً ويحتاج إلى الوصول من أي شبكة دون الاعتماد على جهاز Windows قيد التشغيل.

لا يزال التطبيق modular monolith ولا يضيف خدمات منفصلة. تبقى PWA قابلة للتثبيت، لكنها لا تعد بكتابة offline متزامنة. تحفظ MongoDB سجلاً غير قابل للحذف للحركات، وفهارس idempotency، ومعاملات تكتب السجل وإسقاط الرصيد معاً.

يعني هذا القرار أن البيانات تحتاج Atlas أو MongoDB متاحاً أثناء التشغيل. لا تخزن الأسرار في Git أو العميل، وتستخدم النسخ الاحتياطية JSON المنزلة من واجهة الإعدادات أو من سكربت التشغيل.
