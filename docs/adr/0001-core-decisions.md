# ADR-0001: قرارات MVP الأساسية

الحالة: مقبول

قرر المشروع monolith معياري بـ Next.js كخادم وواجهة في نشر واحد، وSQLite WAL كسجل مخزون، وDrizzle/better-sqlite3. هذا يكفي لجهاز واحد ويقلل التشغيل. PWA قابلة للتثبيت لكنها لا تعد بكتابة offline متزامنة. النشر LAN-only افتراضياً؛ الوصول البعيد يحتاج VPN وHTTPS.
