# تجربة الاستخدام وإتاحة الوصول

اللغة والاتجاه RTL من الجذر. المقاس الأساسي 18px تقريباً وأزرار الإدخال 48px على الأقل. كل لون يرافقه نص عربي ثابت، والحالة لا تعتمد على اللون وحده. لا توجد حركات زخرفية أو counters متحركة أو تمرير تلقائي؛ الانتقالات صفر وتحترم تفضيل تقليل الحركة.

للنموذج تسمية صريحة لكل حقل وأخطاء داخلية ومنطقة live لتأكيد الحفظ. اختيار الوزن يركز حقل الكمية. تفحص اختبارات axe صفحة الدخول؛ والقائمة اليدوية: ترتيب focus منطقي، focus مرئي، تكبير 200%، لا overflow هاتف، تسميات، حجم لمس، وعدم الاعتماد على اللون.
