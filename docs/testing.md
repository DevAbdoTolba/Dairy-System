# الاختبارات

`npm run verify` يشغل التنسيق والlint والأنواع ووحدات المجال وتكامل MongoDB والبناء. تحتاج اختبارات التكامل إلى `MONGODB_URI` صالح؛ إن لم يكن متاحاً تتخطى اختبارات التكامل التي تتصل بقاعدة البيانات بدلاً من محاكاة MongoDB.

`npm run test:e2e` يستخدم قاعدة `dairy_e2e` على MongoDB المحلي في `mongodb://127.0.0.1:27017/?directConnection=true` ويمسحها قبل التشغيل. شغّل `docker compose up -d mongodb` و`npx playwright install chromium` مرة واحدة قبل E2E محلياً. يشغّل Compose MongoDB كـ replica set أحادي حتى تطابق المعاملات Atlas.

تغطي اختبارات المتصفح تسجيل الدخول والإدخال السريع وقاعدة الرصيد السالب وRTL وaxe على هاتف وجهاز لوحي وسطح مكتب. تشمل المراجعة اليدوية ترتيب التركيز ووضوحه والتكبير 200% وعدم وجود تمرير أفقي والنسخ والاستعادة على قاعدة Atlas تجريبية.
