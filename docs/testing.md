# الاختبارات

`npm run verify` يشغل التنسيق والlint والأنواع ووحدات المجال وتكامل SQLite والبناء. `npm run test:e2e` يغطي الدخول والإدخال السريع وقاعدة الرصيد السالب وRTL وفحص axe الأساسي على هاتف ومكتب. قبل E2E محلياً نفذ `npx playwright install chromium` مرة واحدة.

لا تضعف الاختبارات لإخفاء فشل. اختبر يدوياً: تسلسل لوحة المفاتيح، focus، تكبير 200%، الشاشة الضيقة، إعادة الإدخال، التراجع، تنزيل CSV، والنسخ/الاستعادة في قاعدة تجريبية.
