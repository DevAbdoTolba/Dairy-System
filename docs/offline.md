# العمل والمزامنة دون إنترنت

التطبيق PWA قابل للتثبيت على الجهاز اللوحي. بعد أول دخول ناجح بالإنترنت، يخزن عامل الخدمة واجهة التطبيق وآخر نسخة من الشاشات الأساسية، لذلك يمكن فتح لوحة اليوم وتسجيل التصنيع والبيع والمرتجع عند انقطاع الشبكة.

## طريقة الحفظ

- لكل حركة مفتاح `idempotencyKey` ثابت قبل محاولة إرسالها.
- عند غياب الإنترنت تحفظ الحركة في IndexedDB على الجهاز بترتيب إنشائها.
- يظهر الرصيد وملخص اليوم شاملاً الحركات المنتظرة، مع تمييز عددها في شريط حالة المزامنة.
- عند عودة الاتصال يرفع عامل الخدمة الحركات بالترتيب. القيد الفريد في MongoDB يجعل إعادة الطلب آمنة ولا يضاعف الرصيد.
- رفض قاعدة عمل، مثل بيع كمية غير متاحة، لا يُحذف: يظهر كعملية تحتاج مراجعة ويمكن إعادة محاولتها.

## التنبيهات

اضغط **تفعيل التنبيهات** مرة واحدة من الجهاز. يصدر التطبيق تنبيهاً محلياً فور حفظ حركة دون إنترنت، وتنبيهاً آخر بعد اكتمال الرفع. تعمل Background Sync على المتصفحات الداعمة حتى بعد إغلاق نافذة التطبيق؛ وعلى المتصفحات غير الداعمة تبدأ المزامنة عند فتح التطبيق أو عودة الاتصال وهو مفتوح.

التنبيه المحلي الناتج عن حدث داخل التطبيق يعمل دون إنترنت. أما التنبيهات البعيدة من خادم خارجي فتحتاج اتصالاً، ولا يستطيع تطبيق ويب ضمان تشغيل تذكير مجدول بينما الجهاز مغلق تماماً ودون شبكة.

## حدود الأمان والتشغيل

- يلزم أول دخول وتحميل للتطبيق عبر HTTPS قبل الاعتماد على وضع عدم الاتصال.
- لا يسمح التطبيق بالخروج وفي الجهاز حركات غير متزامنة، لحمايتها من الضياع.
- انتهاء جلسة الخادم لا يمسح الحركات؛ تظهر رسالة تطلب الدخول ثم إعادة المحاولة.
- النسخ الاحتياطي والاستعادة وتعديل الإعدادات عمليات خادم وتتطلب اتصالاً. شاشاتها المحفوظة تبقى قابلة للقراءة دون إنترنت.
- من أدوات المتصفح يمكن اختبار الحالة عبر Application → Service Workers ثم Offline، ومراجعة IndexedDB → `dairy-offline`.

عامل الخدمة معطل أثناء `npm run dev` حتى لا يخزن ملفات التطوير المتغيرة. لتجربة عدم الاتصال محلياً شغّل Playwright، أو اضبط `NEXT_PUBLIC_DAIRY_OFFLINE=true` قبل تشغيل خادم التطوير.
