# نموذج البيانات

- `productVariants`: الاسم العربي والوزن ورمز العرض والترتيب والحالة. `weightKg` موجب وفريد بين الأوزان النشطة.
- `inventoryTransactions`: الوزن والنوع والكمية الموجبة وتاريخ العمل ISO والملاحظة والحالة ورابط التصحيح ومفتاح `idempotencyKey` والتواريخ التقنية UTC. الحركات لا تحذف.
- `inventoryBalances`: إسقاط سريع للرصيد الحالي لكل وزن. يعاد بناؤه من السجل عند الاستعادة ولا يعدل يدوياً.
- `appSettings`: اسم المعمل واللغة والمنطقة الزمنية وتاريخ البداية.
- `ownerAccounts`: حساب مالك واحد مع hash من scrypt فقط.
- `loginAttempts`: حد محاولات الدخول دون Redis.

تنشئ MongoDB Atlas فهرساً فريداً لـ `idempotencyKey` وفهارس للتاريخ والوزن. تسجل الحركة وتحدث `inventoryBalances` داخل MongoDB transaction واحدة. يمنع تحديث الرصيد الشرطي عملية بيع أو تسوية نقص تجعل الرصيد سالباً، إلا مع خيار تجاوز ظاهر وسبب إلزامي.
