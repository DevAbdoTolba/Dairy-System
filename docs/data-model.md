# نموذج البيانات

- `product_variants`: الاسم العربي، الوزن، رمز العرض، الترتيب والحالة. الوزن موجب وفريد بين الأوزان النشطة.
- `inventory_transactions`: الوزن، النوع، كمية موجبة، تاريخ العمل ISO، ملاحظة، حالة، رابط التصحيح، مفتاح idempotency وتواريخ تقنية UTC.
- `app_settings`: اسم المعمل واللغة والمنطقة الزمنية وتاريخ البداية.
- `owner_accounts`: حساب مالك واحد مع hash scrypt فقط.
- `login_attempts`: حد محاولات الدخول المحلي دون Redis.

تفعّل SQLite foreign keys وWAL. يمنع التطبيق عملية بيع أو تسوية نقص تجعل الرصيد سالباً، إلا مع خيار تجاوز ظاهر وسبب إلزامي.
